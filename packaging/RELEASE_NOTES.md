Download **MonitorSwap.zip**, unzip it, and follow the [install steps](https://github.com/josedaidone/monitorswap#install): the `Desktop` folder goes on one PC, the `Laptop` folder on the other.

Windows 10/11, 64-bit. The exe is built from this repository's source by GitHub Actions. It is not code-signed, so Windows may ask you to confirm the first run (More info > Run anyway).
